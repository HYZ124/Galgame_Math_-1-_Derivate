# 壁纸文件夹（玩家纪念用）

这里是《导数物语 · 导数篇》的**桌面壁纸集**，一共 18 张，全部有人物出镜。
它们**不参与游戏运行**（`game/` 里没有引用），纯粹是给通关或者半路喜欢上的玩家
拷回桌面当纪念用的。

## 怎么设成桌面壁纸（Windows）

1. 打开本文件夹，挑一张喜欢的；
2. 右键 → **设为桌面背景**（Win11）；或者「照片」里打开 → `…` → 设为 → 背景；
3. 想要随桌面自动换一批：设置 → 个性化 → 背景 → 「照片」→ 文件夹选这里 → 打开幻灯片放映。

多屏 / 带鱼屏用户：`wp11`、`wp12`、`wp16`、`wp18` 是 **2560×1080（21:9）**，其余是 **1920×1080（16:9）**。
16:9 的图放到 2K/2.5K 屏上会轻微放大，不会变形（管线是等比缩放后居中裁切，不是拉伸）。

## 关于这些图

- 全部由本项目自己用 AI 绘图生成、再由工具裁成标准桌面比例，**没有外部素材**，
  玩家可以放心自用（个人桌面、锁屏、壁纸引擎都行）。
- 人物设定与游戏内立绘一致：云曦 = 银白长发 + 月牙流苏发饰 + 白上衣**青色交叉 V 领**汉服 +
  粉蓝褶裙金浪纹；知微 = 棕发低双马尾 + 圆金丝眼镜 + 白衬衫藏青领结 + 香槟色针织开衫（两只肩膀都穿好）。

## 维护：想再加一张壁纸

不要手改 png，走管线（脚本头部有完整说明）：

1. 生图，文件名前缀写成 `wpNN_英文短语`；16:9 用 `1792x1024`，21:9 用 `2560x1080`。
   提示词里一定带上 `no text, no watermark, no letters or numbers`——AI 一写字就是乱码；
   还要带上面那段人物设定，否则衣服会画成旗袍领 / 开衫掉肩。
2. 在 `D:\workspace\galgame-math\tools\make_wallpapers.py` 的 `WALLS` 列表里加一行
   `(前缀, 输出名, 宽, 高)`。
3. `python tools/make_wallpapers.py`（全量重出）或 `python tools/make_wallpapers.py wp13`（只出一张）；
   出完 `python tools/make_wallpapers.py --sheet` 拼一张对照表，检查**头顶有没有被裁掉**、
   有没有乱码字、人物走形没有，再交付。

⚠ 两个已经踩过的坑：`2560x1080` 这种超宽构图很容易把坐着的人物**头顶切掉**（提示词里要写
"camera pulled far back, generous headroom, nothing cropped at the top edge"）；
教室窗外的景色要显式排除鸟居/神社/塔，否则模型爱往那边画。
